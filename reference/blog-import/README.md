# 블로그 레퍼런스 사진

제공받은 블로그 5개에서 본문 사진 220장을 저장했어요. `manifest.json`에 원문·이미지 URL과 파일 경로를 기록했어요.

- `blue/`: 11장
- `carpet/`: 17장
- `contact-sheet/`: 2장
- `flower-shop/`: 8장
- `mixed-studios/`: 21장
- `other-indoor/`: 16장
- `outdoor/`: 79장
- `silver/`: 21장
- `studio-details/`: 3장
- `white/`: 42장

블루는 커튼·테이블과 블루 톤 소파, 카페트는 파란 바닥 공간 기준이에요. 흑백이나 배경이 모호한 실내 컷은 `other-indoor`로 분리했어요. `mixed-studios`는 첫 글의 다른 업체·일상 사진이고, `contact-sheet`는 여러 컷을 합친 비교 이미지예요.

사진은 촬영 준비용 원본 보관 자료이며 사이트에서는 선택한 사진 16장만 추가로 사용해요.
